# Configuración del servidor CS 1.6

Este repositorio contiene una selección de configuraciones del servidor Zombie Escape alojado en Counter-Strike 1.6. No es una copia completa ni autónoma del servidor.

Se incluyen configuraciones de AMX Mod X para los modos Zombie Escape, Zombie Apocalypse y Humans vs. Monsters, además de `mapcycle.txt`.

Por seguridad y para no redistribuir archivos del juego o de terceros, se excluyen los recursos de Counter-Strike, mapas, modelos, sonidos, plugins compilados, logs, listas de usuarios y VIPs, credenciales de base de datos, archivos de servidor privados y respaldos. El `.gitignore` mantiene fuera del repositorio el resto del contenido del host.

Al desplegar estos archivos, se necesitan por separado Counter-Strike 1.6, AMX Mod X, los plugins y los recursos requeridos por la configuración.
